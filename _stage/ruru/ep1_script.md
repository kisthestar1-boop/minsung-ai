# 편의점 알바는 아기 드래곤 (My Part-Timer Is a Baby Dragon) — 1화 「첫 출근」 / Ep.1 "First Shift"

장르: 힐링 개그 일상 판타지 (CANVAS: Comedy + Slice of life)
형식: 1화 12컷, 짧은 개그 + 따뜻한 마무리. 매주 같은 요일.
인물: 루루(아기 드래곤 · 인간 변신 서툼 · 덤벙) / 도윤 점장(무표정 · 커피) / 단골 할머니

개연성 체크
- 왜 드래곤이 편의점에? → 점장이 장난으로 쓴 공고 '야간 알바 구함 (종족 무관)'을 보고 옴
- 왜 바로 채용? → 야간 알바를 석 달째 못 구함
- 왜 도시락을 불로? → 전자레인지를 처음 봄 ("데우는 건 자신 있어요")
- 왜 할머니가 사 감? → 불맛 좋아하는 단골
- 다음 화 연결 → "전자레인지는 내일 가르쳐 줄게" (2화: 전자레인지 수업)

| 컷 | 그림 | 한국어 | English |
|---|---|---|---|
| 1 | 밤 편의점 외관 | (내레이션) 장유동 골목 끝, 24시 편의점. | (N) At the end of a quiet street, a 24-hour convenience store. |
| 2 | 점장, 9시 시계 | 야간 알바 구한 지 석 달째... / 오늘 온다던 신입은... | Three months looking for a night-shift worker... / And the new hire is late... |
| 3 | 루루 문 열고 등장 | 안녕하세요! 공고 보고 왔어요! / '종족 무관'이라고 써 있어서요! | Hi!! I'm here for the job! / It said "all species welcome"! |
| 4 | 점장 무표정 클로즈업 | ...그거 장난으로 쓴 건데. | ...I wrote that as a joke. |
| 5 | 루루 꼬리 숨기며 당황 | 꼬, 꼬리 없어요! 완전 인간이에요! | N-no tail here! I'm 100% human! |
| 6 | 조끼 건네기 | (한숨) ...야간 할 사람이 없으니까. / 지금부터 일해. // 앗, 바로요?! | (sigh) ...Nobody else wants nights. / You start now. // W-wait, right now?! |
| 7 | 전자레인지 가리킴 | 손님이 도시락 사면 데워 드려. 30초. | When a customer buys a lunchbox, heat it up. 30 seconds. |
| 8 | 루루 자신만만 | 데우는 건 제 전문이에요! | Heating things up is my specialty! |

| 11 | 할머니 등장 | 어머, 직화 도시락이네? 이거 줘요~ | Oh my, flame-grilled! I'll take that one~ |
| 12 | 따뜻한 마무리 | ...전자레인지는 내일 가르쳐 줄게. / (내레이션) 그렇게, 아기 드래곤의 첫 출근이 끝났다. | ...I'll teach you the microwave tomorrow. / (N) And so ended the baby dragon's first shift. |
