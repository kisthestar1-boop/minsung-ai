# 새싹 엔진 (Sprout Engine)

새싹 원정대를 기준 게임으로 삼아 꺼내 만드는 우리 게임 엔진이에요.

## 규칙 5가지
1. **자료와 동작을 나눈다** — 숫자·이름·그림은 표(`sprout/data.js`)에, 움직임은 엔진(`sprout/index.html`)에.
2. **조립식 부품** — 캐릭터 = 몸 + 기술 + 효과 + 소리.
3. **신호로 말한다** — "몬스터가 쓰러졌다" 신호에 카드·퀘스트·경험치가 각자 반응.
4. **씬 단위** — 첫 화면·모험·스킬 창·카드 창을 따로 만들고 겹쳐 띄운다.
5. **자동 시험이 문지기** — 첫 2분 시험을 통과한 버전만 올린다.

## 단계
- [x] 학습: Unity · Godot · RPG Maker · Phaser · GDevelop
- [x] 1단계 시작: 영웅·기술·몬스터·카드·스킬 트리 표를 `sprout/data.js`로 분리
- [ ] 1단계 남은 것: 일반 몬스터·지도·퀘스트 표 분리
- [x] 2단계 시작: 시험 스크립트를 `engine/tests/`에 모음
- [ ] 2단계 남은 것: 한 번에 돌리는 문지기 스크립트와 통과 기준 숫자
- [ ] 3단계: 게임 루프·씬·입력·불러오기·효과·저장 모듈화
- [ ] 4단계: 본부에서 표를 고치는 편집 화면
- [ ] 5단계: 두 번째 게임(동물 성 대전)으로 증명

## 시험 (engine/tests)
로컬 서버(`python3 -m http.server 8765`)를 저장소 루트에서 켠 뒤 Playwright로 실행해요.
- `first2min.js` — 새 사용자처럼 첫 화면부터 2분: 시간대별 레벨·처치·카드 수
- `classes3min.js` — 다섯 직업 3분 자동 전투 비교
- `modes.js` — 포획·스킬·저장·다른 모드 점검
- `cards.js` — 강한 몬스터 등장·포획·카드 창
